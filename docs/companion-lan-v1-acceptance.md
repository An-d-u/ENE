# 동반 앱 조기 LAN 수용 확인

2026-09-16: Android 연결·최소 화면을 구현했고 실제 단말 선택/설치 확인을 기다린다. 이 문서는 시험 결과를 기록할 기준표이며 LAN 연결 성공 기록이 아니다.

PC 기준: `codex/companion-lan-v1`, 코드 커밋 `d3d00149`. 현재 턴의 PC 변경은 계획/수용 문서뿐이다. Android는 별도 ENE_APP 저장소의 `codex/companion-tls-v1`, 커밋 `d6671e8`에서 구현했으며 해당 저장소의 `docs/android-connection-validation.md`와 `docs/build-and-install.md`를 따른다. 원래 ENE main에 병합하거나 원격 저장소에 게시하지 않았다.

시험은 `.venv\Scripts\python.exe -m tools.companion_smoke`의 합성 응답으로 시작한다. 이 도구는 임시 등록을 사용하므로 종료 후 재실행은 새 QR이 필요할 수 있다. 실제 대화·API 키·단말 일련번호·QR·토큰은 결과 자료로 남기지 않는다.

단말 접근이 없으면 Task 6을 성공 처리하지 않는다. 사용자와 시험 대상을 정한 뒤 설치하고, 같은 개인 LAN·카메라·왕복을 먼저 확인한다. 방화벽 변경은 실행 파일/포트·개인 프로필·로컬 서브넷으로 범위를 정해 별도 확인을 받는다. 실제 ENE 통합을 확대하거나 외부 AI 비용이 발생하는 시험, Tailscale 설치, 공개 릴리스는 이 확인에 포함하지 않는다.
