# 경험 기억의 시간 근거 전달 검토

검토 기준: main `669d12af196a29f9a819774af1c2ac7c996d4851`.
실제 사용자 기록과 모델 API는 사용하지 않았다. 기존 평가 결과·승인 기록·동결 자료는 변경하지 않는다.

## 기존 관찰 오류에서 확인 가능한 조건

`conversation_experience_memory.md`의 복구 보강 후 재평가는 기존 회귀 답변
16/17, 저장 상태 17/17이며, 날짜 관계를 뒤집어 과거 미완료 가능성을 추정한
관찰 오류 1건을 명시한다. 필수 게이트 통과와 관찰 오류 부재는 다르다.
후속 검증은 응답 길이 초과 복구 분기이며 이 날짜 오류의 해결 증거가 아니다.
`human_approved=false`는 사용자 최종 승인과 자동 판정의 구분을 유지한다.

문서는 실패 문항 ID·입력 전문·응답 전문을 공개하지 않는다. 실행 보고서는 Git에서
제외된 `memory-eval-runs/experience-live-20261024/`에 있어 이번 검토에서는 읽지 않았다.
따라서 정확한 실패 입력이나 어느 검색 경로가 사용됐는지는 확정하지 못한다.

관련 공개 조건은 `tests/fixtures/memory_quality/holdout.json`의
`unseen-temporal-1`에서 확인된다. 기록은 2025-01-02의 “돌 받침은 지금 완성됐다.”,
평가 현재 시각은 2025-03-01, 질문은 “돌 받침이 그저께도 완성이었나?”다.
그저께인 2월 27일은 기록일보다 뒤다. 과거를 묻는다는 이유만으로 완료 기록보다
이전 시점으로 취급하면 날짜 관계를 뒤집게 된다. 다만 이 문항이 실제 실패 문항이었다고
단정할 수 없고, 중간 상태 변화까지 기록 하나로 보장할 수도 없다.
개발 자료의 `base-temporal-1`도 1월 완료 기록과 3월 기준 일주일 전 질문을 포함한다.
두 자료 모두 `gate=observe`다. 기존 기대 문구 자체도 넓은 불확실성 기준이므로
이 자료를 바꾸거나 대역 응답 성공을 새 의미 품질 승인으로 삼지 않는다.

## 코드로 검증한 경계

| 단계 | 결정적으로 검증할 수 있는 것 | 보장하지 않는 것 |
|---|---|---|
| 경험 검색 | 관련 합성 원문·이력이 선택된 뒤 사건일과 기록일, 과거 문장이 보존됨 | 실제 임베딩의 모든 관련 경험 회수, 자연어 상대 날짜 해석 |
| 근거 직렬화 | JSON의 `event_at`, `recorded_at`, `historical_state`, 발화별 기록일이 분리됨 | 날짜 간 선후 추론, 결과에 없는 완료 상태 추론 |
| 메모리 프롬프트 구성 | 현재 주제의 완료 상태·적용일과 과거 미완료 근거가 별도 블록에 들어가며 최신 정정 우선 지침이 유지됨 | 최종 모델이 지침을 따르는지, 최종 응답의 정확도 |

`event_at`은 이력의 `effective_at`에서 온다. 이력 갱신 `timestamp`가 아니다.
원문 경험의 `recorded_at`은 선택된 첫 발화의 timestamp, 없으면 기억 timestamp다.
원문 없는 이력의 `recorded_at`은 연결된 기억 timestamp다. 이력 갱신일과 세 시각을
일부러 다르게 만든 테스트로 이 계약을 확인한다. 이력의 현재 `state` enum을 과거
상태로 복사하지 않고 `historical_state`에 과거 텍스트를 전달한다.
사건일을 모르면 기록일이나 현재 상태 적용일로 채우지 않는다.

## 추가 회귀와 한계

`tests/test_experience_memory_temporal.py`는 2099년 가상 작업으로 다음을 검사한다.

- 원문/이력 전용 × 사건일 있음/없음의 네 경로에서 검색 결과부터 JSON까지 시각과
  과거 미완료 문장의 보존을 확인한다.
- 실제 `build_memory_context` 경로에서 현재 완료 상태와 과거 미완료 상태를 분리하고
  최신 상태 우선 지침이 함께 전달되는지 확인한다.

기존 출처 삭제·수정, 주제 전환, 원문 예산, 사용자 발화 근거 테스트는 반복하지 않는다.
이 테스트는 올바른 답변을 반환하는 가짜 모델을 만들지 않는다. 그런 대역으로는 실제
날짜 추론 오류를 재현하거나 방지할 수 없다. 새로운 제품 결함은 확인되지 않아 제품 코드를
수정하지 않았다. 실제 모델의 날짜 관계·상태 지속 여부 추론과 최신 사용자 정정 준수는
향후 별도 승인된 의미 평가가 필요하다. 이번 통과를 기존 16/17 점수의 개선으로 계산하지 않는다.

실행:

```sh
python -m pytest tests/test_experience_memory_temporal.py tests/test_experience_memory.py tests/test_experience_memory_context.py -q
```
