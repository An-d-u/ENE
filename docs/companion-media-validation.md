## 구현된 동작

PC ENE를 실행하고 동반 앱 서버를 켠 상태에서, 같은 개인 LAN의 Android 한 대를 QR과 PC 명시 승인으로 등록한다. HTTPS/WSS와 PC별 CA를 사용하며 평문 전환이나 인증서 오류 무시 경로는 없다. PC가 현재 표시 대화 전체와 AI 요청·기억·기분·TTS 작업을 소유한다. 앱은 내부 프롬프트나 비밀 설정을 받지 않는다.

폰이 전경에 있고 현재 연결·대화 동기화·재생 준비 조건을 만족하면 폰으로 음성을 보낸다. 준비 거절이나 시작 전 실패는 PC 재생으로 돌아갈 수 있다. **폰 재생 시작 명령을 확정한 뒤에는 실제 소리가 났는지 불확실해도 같은 발화를 PC에서 다시 재생하지 않는다.** 단절·취소 뒤의 다음 발화부터 출력 대상을 다시 정한다. 수동 출력 선택기는 이번 범위에 없다. 브라우저 전용 TTS와 지원되지 않는 형식은 기존 PC 경로를 유지한다.

Live2D는 화면 동영상이 아니라 같은 캐릭터 실행부·현재 모델·공개 설정을 폰에서 렌더링한다. 표정·동작·실제 재생 위치 기반 입 모양을 연결하되 프레임 단위로 완전히 같은 화면을 보장하지 않는다. PC에서 모델을 선택하고 폰은 검증된 자산을 받는다. 쓰다듬기는 PC가 한 세션만 수락하며 정상 종료당 최대 한 번 기록한다. 로컬 예측 표시와 실제 기록을 분리했고, 중복 종료·이전 연결 입력·2초 입력 유실·모델 교체는 중복 기록을 만들지 않는다.

모바일 공통 설정은 허용 키 20개와 편집 가능한 모델 장식만 제공한다. 슬라이더는 로컬 미리보기 후 손을 뗄 때 한 번 저장한다. 저장 중 추가 입력을 막고, 충돌·거절·10초 응답 유실 뒤에는 새 manifest를 읽으며 저장 명령을 자동 재전송하지 않는다. 닫기는 미전송 조정만 취소한다. 기본 표정은 카탈로그로 검증한 PC 기본값을 따르며 눈·입·신체 움직임 파라미터는 직접 편집하지 못한다.

## 지원 한도와 보관

| 구분 | 현재 한도 |
| --- | --- |
| 폰 음성 | 16비트 little-endian PCM, 8~48kHz, 1~2채널; 검증된 비압축 WAV 또는 지원 스트림 |
| 발화 원본 | 최대 180초·36MiB 이하, 실제 형식에 따른 더 작은 상한 적용 |
| 전송 대기 | PC 작업자 우편함+중계 합계 4초 이하, 폰 4초 이하; 각 경계의 바이트 상한도 적용. 전체 프로세스 메모리 보장은 아님 |
| 모델 | Cubism `.model3.json`, 최대 256파일·128MiB; 파일당 32MiB; 텍스처 각 변 8192px |
| manifest / 캐시 | 256KiB / 최대 256MiB·2버전, 내려받는 중인 예약 공간과 사용 중 핀 포함 |
| 표현 이벤트 | 연결·모델·대화·동작 번호 검증; 끊긴 동안의 음성·일회성 동작을 나중에 재생하지 않음 |

음성은 앱의 영구 파일로 저장하지 않는다. 캐릭터 캐시는 서버 신원·CA·등록 세대로 분리한다. 등록 해제·승인된 교체·인증된 등록 폐기 시 사용 중 모델과 스트림을 먼저 해제하고 이전 캐시를 삭제한다. 삭제 실패 시 기존 로컬 등록을 보존하고 오류를 표시한다. 앱을 다시 열어 재시도하며, 새 PC 승인이 이미 이뤄졌다면 PC에서도 등록 상태를 확인한다.

캐시에는 모델 자산과 검증용 정적 목록만 둔다. 현재 설정·장식 보정·표정 선택·동작 번호는 저장하지 않으며, 구형 상태 포함 캐시는 다음 초기화에서 폐기한다. 재접속할 때 서버의 새 manifest를 받은 뒤에만 캐시 자산을 사용한다. 대화·초안은 앱 메모리에만 있어 프로세스 종료 시 사라질 수 있다. WebView는 번들 문서와 현재 해시 자산만 열며 임의 네트워크·파일 URL·일반 JavaScript 인터페이스를 허용하지 않는다.

통합 시험에서 PC 제어 기능 협상 누락과 Android TLS 종료 시 연결 목록 복사 경합을 재현·수정한 뒤 위 전체 명령으로 재검증했다. 포화 시험의 접속 간격은 시험용 가상 시간으로 전진시켰으며 제품의 접속 제한은 완화하지 않았다. JavaScript 수명 시험과 네이티브 경계 대역을 실제 Android WebView 실행으로 간주하지 않는다.

인계 문서 대조 중 등록 변경 시 캐시 삭제 누락과 현재 상태의 디스크 보관을 발견했다. 상태 비보관·구캐시 제거·최신 상태 재사용·핀/다운로드 해제 순서·등록 실패 보존 등 합성 시험 8개를 추가하고 Android 전체 검증 및 APK 파일/해시 검사를 다시 실행했다. PC 소스는 이 후속 보완에서 변경하지 않았다.

로컬 병합 뒤 위 명령으로 다시 검증했다. PC의 개인 설정이 있는 기본 폴더 대신 동일한 main 커밋의 격리 작업 폴더에서 pytest를 실행했고, Android 단위 시험은 이전 결과를 재사용하지 않고 전부 실행했다. 격리 폴더의 Git 미포함 실행 기록은 삭제하지 않았으며, 원격 동기화나 설치는 수행하지 않았다.

## 남은 인수와 배포 경계

- 설치, 실제 PC↔폰 LAN 왕복, QR/OS 권한/Keystore/프로세스 복원.
- Android 기종별 WebGL·외형·발열·메모리, 손가락 좌표·쓰다듬기 횟수, 글자 확대·가로 화면·키보드.
- 실제 소리·AudioTrack 위치·오디오 포커스·통화·블루투스·홈/잠금/회전·체감 입 모양 지연.
- 출시 아이콘, release 서명/빌드, 공개 게시 전 전체 히스토리·산출물 개인정보 검사.
- Cubism 실행부 및 각 모델의 사용·재배포 권리 확인. 번들 고지와 고정 해시 확인만으로 공개 배포 허가를 대신할 수 없다.

Tailscale·LTE/5G·포트 포워딩·방화벽 변경·실제 유료 AI/TTS 호출·단말 설치는 수행하지 않았다. 이 기록을 기존 텍스트 V1의 모든 인수·서명·출시 완료로 해석하지 않는다.
