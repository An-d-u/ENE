# 에네 2D 탑뷰 가상세계 V1 설계

## 목표

에네가 사용자의 명령을 기다리기만 하는 채팅 캐릭터가 아니라, 자기 공간에서 스스로 생활하는 존재처럼 느껴지게 한다. V1은 큰 마을이나 게임 전체를 만들지 않고, 에네의 작은 집과 정원을 중심으로 “관찰형 자율 생활 공간”을 검증한다.

## 확정 범위

- 별도 월드 창을 추가한다.
- 월드는 기존 Live2D 오버레이와 채팅 UI를 대체하지 않는다.
- V1 맵은 `집 밖 정원`과 `집 내부` 두 개로 구성한다.
- 문 타일을 통해 집 밖과 집 내부를 전환한다.
- 에네는 월드 안에서 픽셀 스프라이트로 표시한다.
- 사용자는 에네를 직접 조작하지 않는다.
- 에네는 관심 지점 사이를 스스로 이동하고 머문다.
- V1 자율성은 복잡한 LLM 계획이 아니라 상태 기반 루틴으로 구현한다.

## 제외 범위

- 전투, 퀘스트, 인벤토리, 성장 시스템
- 넓은 마을 전체, 여러 NPC, 상점 시스템
- 사용자가 직접 에네를 조작하는 플레이어 컨트롤
- 완성형 에네 전용 픽셀 아트 제작
- 장기 시뮬레이션 저장 및 복잡한 생활 AI

## 사용자 경험

사용자는 트레이 메뉴나 ENE UI의 진입 버튼을 통해 “에네의 집” 월드 창을 연다. 창이 열리면 작은 탑뷰 맵이 보이고, 에네는 정원과 집 내부를 오가며 스스로 행동한다.

바깥 맵에는 집, 길, 정원, 연못, 밭 같은 작은 지점이 있다. 집 문에 도달하면 내부 맵으로 전환된다. 내부 맵에는 책상, 침대, 창가, 휴식 공간이 있다. 에네는 현재 상태에 따라 특정 장소에 잠시 머물거나 다음 장소로 이동한다.

V1에서 사용자는 직접 이동 키를 누르지 않는다. 핵심은 “내가 조작하는 게임”이 아니라 “에네가 자기 공간에서 살아 움직이는 모습을 보는 것”이다.

## 기술 접근

월드 렌더링은 Phaser를 사용한다. Phaser는 타일맵, 스프라이트 애니메이션, 충돌, 씬 전환 같은 2D 게임 기본 기능을 제공하므로 직접 Canvas 엔진을 만드는 것보다 V1 검증에 적합하다.

PyQt 쪽에는 새 `WorldWindow`를 추가한다. `WorldWindow`는 `QWebEngineView`를 사용해 `assets/world/index.html`을 로드한다. 기존 `OverlayWindow` 구조와 유사하지만, 투명 오버레이가 아니라 일반 월드 창으로 동작한다.

웹 자산은 `assets/world/` 아래에 둔다.

- `index.html`: Phaser 월드 진입점
- `style.css`: 월드 창 기본 스타일
- `world.js`: Phaser 게임 초기화와 씬 등록
- `maps/`: 집 밖과 집 내부 맵 데이터
- `sprites/`: 임시 에네 픽셀 스프라이트와 타일 이미지

파이썬과 웹 월드의 연결은 V1에서 최소화한다. WebChannel을 통해 현재 무드 상태나 설정 값만 전달하고, Phaser 쪽은 이동 루틴과 맵 전환을 자체적으로 처리한다.

## 주요 구성 요소

### `WorldWindow`

새 PyQt 창이다. ENE 앱 수명주기 안에서 생성되며, 사용자가 트레이 메뉴나 버튼으로 열 수 있다. 창을 닫아도 ENE 앱 자체는 종료되지 않는다.

### `WorldBridge`

웹 월드에 필요한 최소 상태를 전달한다. V1에서는 읽기 중심으로 설계한다.

- 현재 무드 요약
- 월드 설정
- 향후 확장을 위한 이벤트 수신 지점

### Phaser 월드

월드의 실제 렌더링과 행동 루틴을 담당한다.

- 집 밖 씬
- 집 내부 씬
- 타일 충돌
- 문 전환
- 에네 스프라이트 걷기 애니메이션
- 관심 지점 기반 자동 이동

### 자율 행동 루틴

에네는 현재 씬의 관심 지점 목록에서 다음 목적지를 고른다. 목적지에 도착하면 일정 시간 머문 뒤 다음 목적지를 선택한다.

V1의 선택 규칙은 단순하게 유지한다.

- 평온한 상태: 창가, 연못, 책상 같은 조용한 지점 선호
- 활기 있는 상태: 정원, 밭, 길 같은 바깥 지점 선호
- 피곤한 상태: 침대나 실내 휴식 지점 선호

무드 상태를 받을 수 없으면 기본 루틴으로 동작한다.

## 데이터 흐름

1. 사용자가 월드 창을 연다.
2. `WorldWindow`가 `assets/world/index.html`을 로드한다.
3. WebChannel이 준비되면 웹 월드는 필요한 초기 상태를 요청한다.
4. Phaser가 집 밖 씬을 시작한다.
5. 에네 루틴이 다음 목적지를 선택한다.
6. 에네가 타일 단위 경로로 이동한다.
7. 문 타일에 도달하면 집 내부 또는 바깥 씬으로 전환한다.
8. 무드 상태가 갱신되면 다음 목적지 선택에 반영한다.

## 오류 처리

- 월드 HTML이 없으면 콘솔에 경고를 남기고 창은 빈 상태로 두지 않는다.
- Phaser 로드 실패 시 웹 화면에 간단한 오류 메시지를 표시한다.
- WebChannel 연결이 없어도 월드는 기본 루틴으로 동작한다.
- 맵 데이터가 잘못되면 해당 씬을 시작하지 않고 오류 화면을 표시한다.
- 스프라이트 자산이 없으면 임시 대체 마커를 사용한다.

## 테스트 및 검증

### 수동 검증

- ENE 실행 후 기존 오버레이가 정상적으로 뜬다.
- 월드 창을 열 수 있다.
- 집 밖 맵이 표시된다.
- 에네 픽셀 스프라이트가 표시된다.
- 에네가 사용자 조작 없이 이동한다.
- 문 타일을 통해 집 내부로 전환된다.
- 내부 문 타일을 통해 집 밖으로 돌아온다.
- 월드 창을 닫아도 ENE 앱은 종료되지 않는다.
- 기존 채팅, Live2D, 트레이 메뉴가 깨지지 않는다.

### 자동 테스트

- `WorldWindow`가 올바른 HTML 경로를 계산하는지 테스트한다.
- 월드 창 생성 로직이 기존 앱 초기화와 충돌하지 않는지 테스트한다.
- WebChannel 브리지의 기본 상태 반환을 테스트한다.

## V2 후보

- 에네 전용 픽셀 스프라이트 제작
- 시간대에 따른 조명과 배경 변화
- 기억, 일정, 약속에 따른 행동 지점 선택
- 사용자가 월드 안 사물에 메모를 붙이는 기능
- 마을 광장, 숲길, 작은 상점 같은 확장 맵
- Live2D 오버레이와 월드 행동의 감정 동기화
