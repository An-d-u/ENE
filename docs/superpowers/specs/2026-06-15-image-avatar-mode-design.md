# 이미지 아바타 모드 설계

## 목표

ENE에 Live2D 외의 아바타 표시 방식을 추가한다. 이미지 아바타 모드는 사용자가 NAI 등으로 생성한 캐릭터 이미지를 바로 사용할 수 있게 하는 것이 핵심이다. Live2D처럼 정교한 리깅이나 입 모양 전환을 요구하지 않고, 낮은 제작 비용으로 원하는 캐릭터를 옆에 둘 수 있게 만든다.

## 핵심 판단

- 이미지 모드는 Live2D의 하위 기능이 아니라 별도 아바타 모드로 다룬다.
- 감정 이미지는 영문 감정 키 파일명으로 자동 발견한다.
- `normal` 이미지는 필수이고, 다른 감정 이미지는 선택이다.
- 감정 이미지가 없으면 `normal` 이미지로 대체한다.
- TTS 재생 중에는 입 열린 이미지로 교체하지 않는다.
- TTS 재생 중에는 현재 이미지가 위아래로 움직이는 방식으로 말하는 상태를 표현한다.
- NAI 기반 이미지는 감정마다 구도와 여백이 달라질 수 있으므로, 위치와 크기는 이미지 파일별로 저장한다.

## 파일 구조

사용자는 캐릭터별 폴더를 만들고 감정 키와 같은 이름의 이미지 파일을 넣는다.

```text
avatar_images/my_character/
  normal.png
  joy.png
  sad.png
  angry.png
  surprised.png
```

지원 확장자는 V1에서 `png`, `webp`, `jpg`, `jpeg`로 제한한다. 같은 감정 키에 여러 확장자가 있으면 `png`, `webp`, `jpg`, `jpeg` 순서로 우선한다.

## 설정 구조

설정에는 현재 아바타 모드, 이미지 폴더, 이미지별 배치값을 저장한다.

```json
{
  "avatar_mode": "image",
  "image_avatar_folder": "avatar_images/my_character",
  "image_avatar_placements": {
    "avatar_images/my_character/normal.png": {
      "scale": 1.0,
      "x_percent": 50,
      "y_percent": 50
    },
    "avatar_images/my_character/joy.png": {
      "scale": 0.94,
      "x_percent": 52,
      "y_percent": 48
    }
  }
}
```

배치 키는 감정명이 아니라 이미지 파일 경로를 사용한다. 같은 감정 키라도 파일을 교체하면 구도가 달라질 수 있기 때문이다. 파일 교체 감지는 V1에서 자동으로 처리하지 않고, 사용자가 다시 조절하는 방식으로 둔다.

## 감정 해석 흐름

1. 앱은 이미지 아바타 폴더를 스캔한다.
2. 파일명에서 감정 키를 추출한다.
3. `normal` 이미지가 없으면 이미지 모드는 설정 오류 상태로 표시한다.
4. 응답 감정이 `joy`이고 `joy` 이미지가 있으면 해당 이미지를 사용한다.
5. `joy` 이미지가 없으면 `normal` 이미지를 사용한다.
6. 선택된 이미지 파일 경로의 배치값을 적용한다.
7. 해당 이미지의 배치값이 없으면 기본 배치값을 적용한다.

## 설정 UI

모델 설정 탭은 아바타 모드 선택을 먼저 보여준다.

- `Live2D`
- `이미지`

이미지 모드가 선택되면 다음 항목을 보여준다.

- 이미지 캐릭터 폴더 선택
- 폴더에서 발견된 감정 이미지 목록
- 선택한 이미지의 미리보기
- 선택한 이미지의 X 위치, Y 위치, 크기 조절
- 저장 전 실제 오버레이와 같은 기준으로 미리보기 반영

감정 목록에서 사용자가 `joy.png`를 선택하면 실제 채팅에서 `joy` 감정이 나오기를 기다리지 않고 바로 `joy.png`의 배치를 조절할 수 있어야 한다.

## 런타임 표시

Live2D 런타임은 기존 PIXI Live2D 모델을 로드한다. 이미지 아바타 런타임은 선택된 이미지 파일을 표시하고, 같은 배치 설정 개념을 적용한다.

이미지 모드에서는 Live2D 파라미터 조절 UI를 숨긴다. Live2D 전용 기능인 파라미터 오버라이드, 내장 idle 모션, 눈 깜빡임, 파츠 기반 립싱크는 이미지 모드 V1 범위에 포함하지 않는다.

## TTS 말하기 연출

TTS 재생 중에는 기존 립싱크 신호의 강도를 이미지 바운스 강도로 재사용한다. 이 값은 입 모양 변경이 아니라 Y 위치의 일시적 오프셋으로만 사용한다.

```text
최종 Y 위치 = 저장된 Y 위치 + TTS 바운스 오프셋
```

TTS가 끝나거나 중단되면 오프셋을 0으로 돌린다. 사용자가 저장한 배치값은 변경하지 않는다.

## 오류 처리

- 이미지 폴더가 없으면 설정 화면에 폴더를 다시 선택하라는 상태를 표시한다.
- `normal` 이미지가 없으면 런타임은 이미지 모드를 로드하지 않고 오류 문구를 표시한다.
- 감정 이미지 파일이 로드 실패하면 `normal` 이미지로 대체한다.
- `normal` 이미지도 로드 실패하면 기존 Live2D 오류 표시와 비슷한 방식으로 원인을 보여준다.

## 테스트

- 이미지 폴더 스캔이 감정 키를 올바르게 추출하는지 테스트한다.
- `normal` fallback이 동작하는지 테스트한다.
- 이미지 파일별 배치값이 저장되고 다시 읽히는지 테스트한다.
- 감정 이미지가 없을 때 `normal` 이미지와 `normal` 배치가 쓰이는지 테스트한다.
- 이미지 모드에서 Live2D 파라미터 UI가 숨겨지는지 테스트한다.
- TTS 신호가 배치 저장값을 바꾸지 않고 일시적 바운스만 만드는지 테스트한다.

## V1 제외 범위

- 이미지 생성 API 내장
- 감정별 입 열린 이미지와 닫힌 이미지 세트
- 눈 깜빡임용 별도 이미지 세트
- 이미지 파츠 분리
- 자동 inpaint 보조
- 파일 교체 자동 감지와 배치 재설정 안내
