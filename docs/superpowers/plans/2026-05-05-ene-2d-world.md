# ENE 2D World Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 에네가 별도 창에서 집 밖 정원과 집 내부를 오가며 자율적으로 움직이는 2D 탑뷰 월드 V1을 만든다.

**Architecture:** PyQt에는 `WorldWindow`와 `WorldBridge`를 추가하고, 기존 `ENEApplication`과 `TrayIcon`에서 별도 월드 창을 열도록 연결한다. 실제 2D 월드는 `assets/world/` 아래의 Phaser 웹 자산이 담당하며, V1에서는 로컬 상태 기반 루틴으로 집 밖/집 내부 씬 전환과 자동 이동을 구현한다.

**Tech Stack:** Python 3.11+, PyQt6, QWebEngineView, QWebChannel, Phaser 3, pytest

---

  - 트레이 메뉴와 월드 창 제목 번역을 추가한다.

  - Phaser 월드 진입점과 V1 월드 로직을 둔다.
