# 대화 기기 정보 전달

PC의 **설정 → 동작 설정 → 대화 컨텍스트**에서 켤 수 있다. 기본값은 OFF이며 PC와 모바일 대화에 공통 적용된다. 앱을 다시 빌드하거나 별도로 설정할 필요는 없다.

설정을 저장한 뒤 새로 시작하는 일반 응답부터 적용된다. 설정창의 미리보기만으로는 켜지지 않으며 취소·저장 실패 시 기존 값이 유지된다. 이미 생성 중인 응답에는 영향을 주지 않는다. 생활 기록 생성 등으로 보류된 일반 응답도 실제 생성이 시작되는 시점의 저장 설정을 사용한다.

## 전달하는 정보

- 일반 텍스트와 PC 첨부 요청이 PC에서 왔는지 모바일 앱에서 왔는지만 전달한다.
- 수정·리롤은 최초 메시지의 기기가 아니라 수정·리롤을 실행한 기기를 기준으로 한다.
- 음성이 재생되는 기기, PC·휴대폰의 연결 여부와는 무관하다.
- 자동 발화, 생활 기록, 요약, 기억 추출 및 별도 명령 작업에는 기기 문맥을 추가하지 않는다.
- 위치·IP·하드웨어 모델·운영체제 정보는 전달하지 않는다.

AI에는 현재 요청의 일시적 정보라는 점과, 이를 근거로 위치·활동·화면 접근·도구 권한을 추정하거나 답변 길이·말투를 일괄 변경하지 말라는 안내가 함께 전달된다.

## 저장 경계와 한계

로컬 설정에는 `include_input_device_context`의 ON/OFF만 저장한다. 직접 주입한 기기 문맥은 최종 응답 요청에만 붙이며, 채팅 원문·공급자 대화 이력·검색 질의·사용자 프로필·장기 기억에 추가하지 않는다.

OFF는 이후 요청의 전달을 중단한다. 이미 AI 공급자에 전달한 정보를 회수하는 것은 아니다. AI가 기기를 응답 본문에 직접 언급하면 그 일반 응답은 기존 대화 기록에 남을 수 있다. 따라서 AI 출력까지 완전히 삭제하거나 기기에 관한 언급을 차단하는 기능은 아니다.

## 유지보수

요청 출처는 인증·수락 경계를 통과한 `RequestRef`에서 가져와 응답 워커 시작 전에 고정한다. `request_device`는 선택적 공급자 인자이며 생략하면 기존 동작을 유지한다. 합성 기본 출처나 마지막 연결 기기로 사용자의 기기를 추정하지 않는다.

공급자를 추가할 때는 텍스트·지원되는 이미지 입력·메모리 없는 전송·내부 재시도에서도 최종 입력과 `history_user_content`를 분리해야 한다. 기기 문맥은 검색이 끝난 후 추가하고 형식 복구용 독립 요청에는 넣지 않는다.

관련 검증은 `tests/test_input_device_*.py`에 있다. 외부 과금 호출 없이 합성 입력과 가짜 전송 계층으로 요청·이력·설정 수명을 확인한다. 실제 휴대폰 조작과 실제 LLM의 반응 품질은 별도 시험 대상이다.
