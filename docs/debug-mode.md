# 디버그 로그

`설정 → 동작 → 디버그 → 디버그 로그 저장`을 켜고 설정을 저장하면 즉시 적용됩니다. 기본값은 꺼짐입니다. 다시 끄고 저장하면 진행 중인 요청을 포함해 이후 기록을 중단합니다. 기존 로그는 자동으로 삭제하지 않습니다.

## 저장 위치

- 소스 실행: 소스 루트의 `log/`
- 실행 파일 배포: `ENE.exe`가 있는 폴더의 `log/` (패키지 임시 해제 폴더가 아님)
- 파일: `debug-YYYY-MM-DD.jsonl`, 컴퓨터의 현지 날짜 기준
- 인코딩: UTF-8, BOM 없음

한 줄이 하나의 JSON 이벤트입니다. 일반 텍스트 편집기로 열 수 있으며, JSON 안의 줄바꿈은 `\n`으로 표시됩니다. 파일을 공유할 때에는 내용을 먼저 확인하세요. 프롬프트 전문에는 시스템 지침, 대화 기록, 기억·프로필 등 실제로 모델에 보낸 내용이 포함됩니다. `log/`는 Git에서 제외됩니다.

## 기록 항목

| 항목 | 설명 |
| --- | --- |
| `timestamp` | 시간대가 포함된 기록 시각 |
| `request_id` | 한 요청의 시작·결과를 연결하는 식별자 |
| `stage` | `llm` 또는 `tts` |
| `provider`, `model` | 공급자와 요청한 모델명 |
| `event` | `request`는 시작, `result`는 완료 |
| `request` | LLM에 전달한 본문 전체. Gemini는 시스템 설정·SDK 대화 기록·현재 입력을 포함. TTS는 합성 텍스트와 음성 식별 설정을 포함 |
| `elapsed_seconds` | 호출 시작부터 응답 또는 오류 수신까지 걸린 시간(초) |
| `status` | 성공 `success`, 오류 `error`, 취소 `cancelled` |
| `error_body` | HTTP 오류 응답 원문 |
| `error_message`, `traceback` | 예외 메시지와 호출 추적 |
| `original_error_message`, `original_traceback` | 사용자용 오류로 바꾸기 전에 별도로 보존한 원본 예외(해당할 때만) |

채팅뿐 아니라 같은 클라이언트를 사용하는 요약·문서·생활 기록 등의 생성도 기록합니다. ENE가 재시도하는 경우 각 호출에 별도 ID가 생깁니다. 시작 이벤트만 있다면 요청 처리 중이거나, 실행 종료·디버그 해제 등으로 완료 기록이 남지 않은 경우입니다.

이미지·오디오 바이너리는 저장하지 않습니다. 인증 헤더와 설정의 API 키를 기록 대상에서 제외하고, 알려진 키가 오류에 포함되어 있으면 가립니다. 그 외 텍스트와 오류는 길이를 잘라내지 않습니다. 일반 콘솔의 원문 비노출 동작은 그대로 유지합니다.

## 시간과 모델명의 범위

시간은 모델 호출 자체를 측정합니다. 프롬프트 조립·메모리 검색·대기열·음성 재생 시간은 포함하지 않습니다. 스트리밍 TTS는 첫 요청부터 마지막 청크를 소비할 때까지이며, 소비 측 대기가 있으면 그 대기 시간도 포함됩니다. 전체 대화 턴에 여러 호출이 있으면 각각의 시간이 기록됩니다.

GPT-SoVITS와 GenieTTS는 선택된 실제 모델명을 응답으로 제공하지 않습니다. 이 경우 `model`은 `null`이고 공급자, 참조 음성 경로, 캐릭터·모델 디렉터리 등 ENE가 아는 설정을 남깁니다. 모델명이 있는 OpenAI 계열·ElevenLabs·Fish Audio는 요청한 모델명을 기록합니다.

브라우저 기본 음성(`browser_speech`)은 웹뷰가 자체 합성과 재생을 담당하므로 이 서버 생성 로그의 대상이 아닙니다.

## 저장 실패와 보관

폴더 쓰기 권한이나 디스크 공간 때문에 기록에 실패하면 콘솔에 원문이 없는 안내를 출력하고 대화·음성 생성을 계속합니다. 로그는 자동 압축·삭제하지 않으므로 필요한 진단이 끝나면 디버그를 끄고 불필요한 날짜 파일을 삭제하세요.
