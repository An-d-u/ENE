# 휴대폰 사진·음성 입력과 배경

PC ENE와 ENE_APP을 모두 대응 소스로 업데이트하고 앱을 로컬 빌드한다. 기존 등록·Core·모델을 다시 받을 필요는 없다. APK·모델·SDK Core는 공개 저장소나 릴리스에 올리지 않는다.

## 사진 보내기

입력창의 `＋ → 사진 선택`에서 정지 사진을 최대 4장 선택한다. 지원 형식은 JPEG·PNG·정지 WebP다. HEIC·동영상·움직이는 이미지는 이번 입력 범위가 아니다. 선택만으로 사진이 PC에 전달되지는 않는다. 미리보기에서 제거할 수 있고, 전송 버튼을 눌러야 업로드한다. 사진만 보내는 것도 가능하다.

원본은 읽기만 하며 앱이 방향을 반영하고 메타데이터·원래 파일명을 제거한 사본을 만든다. 읽기 상한은 원본 32 MiB·한 변 32,768·1억 픽셀, 전송은 긴 변 2,048·장당 4 MiB·전체 16 MiB다. 큰 사진은 축소하며 준비 실패 시 기존 초안은 유지한다. 전체 사진 보관함 권한은 요청하지 않는다.

사진은 PC에서 선택한 이미지 지원 AI 제공자에게 전달될 수 있다. 이미지 미지원 모델이면 다른 모델이나 OCR로 자동 대체하지 않는다. 전송 실패 시 텍스트만 몰래 보내지 않는다.

연결이 끊기면 같은 요청 ID로 접수 상태를 먼저 조회한다. 미접수가 확인되면 `미접수 사진 다시 전송`으로 직접 재시도할 수 있다. 중복 자동 전송은 하지 않는다. 사진 초안은 같은 프로세스의 회전·사진 선택기 왕복·재접속에서 유지되지만 앱 프로세스 종료 뒤 복원하지 않는다. 제거·접수 확인·등록 변경 때 앱 소유 임시 사본을 정리하며 사용자 원본은 삭제하지 않는다.

현재 등록에서 이 기능으로 보낸 사진만 대화에 썸네일로 표시한다. 과거 PC 전용 첨부는 그대로 PC에서 확인한다. 썸네일은 원본 다운로드가 아니며 최대 320px·128 KiB이고, 앱 캐시는 디코드 예산을 포함해 8 MiB 이하다. 수정은 텍스트만 바꾸며 기존 사진은 PC에 유지한다. 리롤도 같은 사진을 사용한다.

## 음성 입력

`＋ → 음성 입력 · PC에서 인식`을 누를 때만 마이크 권한을 요청한다. 녹음 뒤 `완료`를 누르면 PC에서 인식하고 입력창에 결과를 넣는다. **대화는 자동 전송하지 않는다.** 입력 내용을 확인한 뒤 전송한다.

PC의 STT 모델·언어·장치·최소/최대 녹음 설정을 시작 시 가져온다. 휴대폰에서는 PCM16LE·16kHz·모노로 최대 30초 또는 PC의 더 짧은 한도까지 녹음한다. 최대 길이에 도달하면 녹음만 멈추며 완료/취소를 기다린다. 이 확인 대기는 60초 뒤 취소된다.

인식 엔진은 PC의 기존 faster-whisper다. PC PTT 활성화 여부와 별개이며 PC 마이크를 켜지 않는다. PTT와 모바일은 동시에 추론하지 않으며, 엔진 초기 다운로드와 CUDA 실패 시 CPU 복구는 기존 PC 동작을 유지한다. 모델 준비와 인식은 최대 120초까지 기다린다. 제한을 넘겨 결과를 폐기해도 실제 엔진 작업이 끝날 때까지 다음 추론을 시작하지 않는다.

홈 이동·잠금·화면 재생성·연결 종료·대화 교체·다른 채팅이나 음성 출력 시작 시 녹음/전사를 취소한다. 복귀 시 자동 녹음하지 않는다. 녹음 중 초안이 변경되면 결과 확인창에서 명시적으로 추가해야 한다. 연결이나 대화가 바뀌면 보관된 전사 결과도 폐기한다. 입력창과 합친 결과는 UTF-8 16 KiB를 넘을 수 없다. 녹음과 미전송 결과는 메모리에만 두며 파일·로그에 저장하지 않는다.

## 배경 및 효과

오른쪽 위 `⋯ → 배경 및 효과`에서 기본 배경, 단색, 사진을 선택하고 어둡기 0–75%·사진 흐림 0–16을 조절한다. 휴대폰 전역 설정이며 PC에 전송하지 않는다. 사진은 앱의 백업 제외 영역에 정규화한 사본으로 저장한다.

효과는 배경에만 적용한다. 캐릭터 크기·움직임·연결·모델 수명은 바꾸지 않는다. 새 사진과 설정이 정상 저장되기 전에는 이전 정상 사본을 지우지 않는다. 손상되거나 누락된 배경은 기본 화면과 오류 안내로 복구한다.

## 검증 범위

계약 사례는 `contracts/companion/v1/chat_images_cases.json`, `stt_input_cases.json`이며 두 저장소에서 동일하게 검사한다. 사진 준비·전송·원장 조회·STT 취소/초안 경합·배경 저장 실패에는 합성 데이터만 사용한다. 일반 CI와 로컬 APK 빌드는 실제 단말 사용 확인을 대체하지 않는다.

미확인: 실제 사진 선택기·마이크 권한/녹음 품질·기기 잠금과 회전·작은 화면/큰 글자·배경의 장시간 메모리와 GPU 동작. 실제 기기 설치 시험과 Live2D 출시 허가 확인은 별도다.
