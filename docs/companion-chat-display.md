# 휴대폰 대화 표시 동기화

PC의 **설정 → 동작 → 메시지 분할 표시**를 휴대폰도 따른다. 별도의 휴대폰 분할 설정은 두지 않는다. PC ENE와 ENE_APP 양쪽에 `chat_display_v1` 지원 코드가 필요하다.

## 표시 규칙

- 켜면 PC와 동일하게 줄바꿈과 긴 문장 경계에서 말풍선을 나눈다. 끄면 원본 메시지 하나를 말풍선 하나로 표시한다.
- 설정 미리보기도 전달한다. 설정 창에서 취소하면 휴대폰도 복원된 값을 받는다. PC 대화창의 웹 페이지가 아직 준비되지 않았더라도 설정 변경을 전달한다.
- 시간과 수정·생각·리롤 아이콘은 원본 메시지의 마지막 말풍선 바깥에 한 번만 표시한다. 작은 화면이나 큰 글씨에서는 아래쪽으로 배치한다.
- 수정·리롤 대상은 기존과 같이 마지막 대화 한 쌍이다. 분할은 화면 표시만 바꾸며 원문, 메시지 ID, 저장 내용과 요청 대상을 바꾸지 않는다.
- 휴대폰의 대화창 높이·캐릭터 크기·위치 설정은 그대로 유지한다. 분할 변경은 캐릭터나 음성 세션을 다시 시작하지 않는다.

## 연결과 호환성

설정은 인증된 기존 WSS 연결에서만 전달한다. 전체 설정 파일 대신 분할 여부와 표시 revision만 전송한다. 계약은 [표시 동기화 계약](../contracts/companion/v1/chat_display.md)을 참고한다.

연결·전경 복귀 때 한 번 조회하고 연결 중 변경은 PC가 알린다. 응답이 5초 동안 없으면 채팅 연결을 끊지 않고 마지막 정상 값을 유지한다. 다음 전경 복귀나 재연결 때 다시 확인한다. 같은 등록에서는 메모리의 값을 임시 유지하지만 등록 해제·교체 때 비운다. 앱 파일에는 저장하지 않는다.

구버전 PC는 분할 없이 기존 채팅을 유지하고 업데이트 안내를 표시한다. 구버전 APK도 PC의 기본 채팅은 계속 사용할 수 있지만 새 표시 기능은 사용할 수 없다. 이 기능만을 위해 재페어링하거나 앱 데이터를 삭제할 필요는 없다.

## 유지보수와 확인

양쪽 저장소의 `chat_display_cases.json`과 `chat_display_split_cases.json`은 같은 합성 기대값을 사용한다. 분할 동작을 바꾸려면 PC의 실제 JavaScript 함수와 Android 계산이 모두 같은 결과를 내는지 검사한다. 허용 최대 본문도 잘라내지 않으며, Android는 화면에 보이는 조각만 구성한다.

설정 전환 시 읽던 원문 위치를 새 배치에 매핑하고, 하단을 보고 있었다면 하단을 유지한다. 생각 펼침 상태와 입력·편집 초안은 표시 설정 변경만으로 초기화하지 않는다. 실제 단말의 글꼴·화면 크기·회전·키보드 조합은 별도 인수 시험 대상이다. 자동 검사나 계측 APK 빌드 성공을 실제 기기 시험 성공으로 보지 않는다.

APK는 사용자 로컬에서 빌드한다. Core·모델·APK·설정·대화 자료는 공개 저장소나 릴리스에 추가하지 않는다.
