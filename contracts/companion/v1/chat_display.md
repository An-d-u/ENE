# 대화 표시 설정 확장

선택 능력 `chat_display_v1`은 기존 TLS/WSS 버전 1에서 협상한다. 미디어 능력과 독립적이다.
표시 브리지가 연결된 PC만 능력을 광고한다. 대화 원문·ID·revision·모델·음성 상태는 변경하지 않는다.

## 메시지

공통 필드는 `type`, `protocol_version: 1`, 양의 정수 `registration_generation`,
UUID `server_epoch`와 `connection_generation`이다.

- APP → PC `chat_display_request`: 공통 필드만 전송한다.
- PC → APP `chat_display_state`: `display_revision`(0..9007199254740991 정수),
  `message_split_enabled`(엄격한 불리언)을 추가한다.

각 봉투는 UTF-8 2 KiB 이하이다. 송신 방향·협상 능력·현재 연결 식별자를 검사한다.
대화 식별자·본문·개인 설정 전체·경로를 포함하지 않는다. 알 수 없는 필드 처리는 기존 codec 규칙을 따른다.

## 동기화

PC의 메시지 분할 resolver가 초기값·저장·미리보기·취소 복원을 통지한다.
실제 값이 바뀔 때만 표시 revision을 올리고 현재 연결에 state를 발행한다.
APP은 최초 Ready에 표시 능력이 없으면 즉시 false/미지원으로 확정하며 확장 응답을 기다리지 않는다.
지원 연결은 extensions_ready 확인 후 조회한다. 화면 복귀·재연결은 재조회하되 동시 한 개만 유지한다.

같은 연결의 낮은 revision은 무시한다. 같은 revision/같은 값은 대기를 해제하며,
같은 revision/다른 값은 기존값을 보존하고 오류로 표시한다. 새 연결은 revision 비교를 초기화한다.
조회가 5초를 넘으면 표시 설정만 실패로 표시한다. 늦게 온 유효 상태는 복구한다.
정상 상태 폴링이나 타임아웃 직후 자동 반복 요청은 하지 않는다.

확정값은 같은 인증서/등록의 재연결 중에만 메모리에 유지한다. 다른 등록·등록 해제·앱 재시작은
false부터 시작한다. 구형 PC는 기존 한 말풍선과 업데이트 안내, 구형 APK는 기존 동작을 유지한다.

## 표시

분할은 원본 ID 하나 아래의 표시 전용 조각이다. PC JS의 줄바꿈/72 UTF-16 길이/문장부호 규칙을
공통 합성 사례로 검증한다. 편집은 원본 전체 텍스트를 사용한다.
시간·수정·생각·리롤은 원본 묶음당 한 번이다. 기존 마지막 대화 한 쌍 권한은 유지한다.
